# F08 — ชวนซื้อซ้ำตามรอบ (กระถาง · ดิน · ปุ๋ย)

> Milestone **M4** · Effort ~5 ชม. · Cost 0 · ต้องมีก่อน: F03

## 1. ทำไม

- ของสิ้นเปลือง (ดินปลูก ปุ๋ย กระถางใหม่) คือ **รายได้ซื้อซ้ำที่คาดเดาได้** และระบบรู้ล่วงหน้าแล้วว่าลูกค้าแต่ละคนจะต้องใช้เมื่อไร (`repot_months`, `fertilize_days`)
- ชวนตอนที่ลูกค้า **ต้องใช้จริง** = ช่วยเหลือ ไม่ใช่ขายของ — ถูกจังหวะและไม่ยัดเยียด (P1: ไม่มีตะกร้า ทุกอย่างจบที่ LINE)

## 2. UX — จุดชวน 3 จุด (ไม่มีจุดอื่น)

| จังหวะ | ที่แสดง | ข้อความ/ปุ่ม |
|---|---|---|
| **งาน repot เตือนล่วงหน้า 14 วัน** (F03 สร้างอยู่แล้ว) | การ์ดงานใน `/today`, `/garden/[id]` | "ถึงเวลาเปลี่ยนกระถางให้ **เจ้าอ้วน** แล้ว · ตอนนี้ 8 นิ้ว → แนะนำ **10 นิ้ว** · ดินสูตรร้าน: {soil_mix}" · [ถามร้านเรื่องกระถาง+ดิน] |
| **งานปุ๋ยครั้งแรกของฤดู** (ครั้งแรกหลังเดือนงดปุ๋ย) | การ์ดงาน | "ปุ๋ยที่ร้านใช้กับต้นนี้: {fertilizer_note}" · [ถามร้านเรื่องปุ๋ย] |
| **ตอบ check-in ว่า 'ดูไม่ค่อยดี' ด้วยอาการที่เกี่ยวกับดิน/ราก** (F06) | ผลลัพธ์ check-in | ปุ่มถามร้านที่แนบอาการ (ไม่เสนอขายของตรง ๆ) |

- กด "รดแล้ว"/"ทำแล้ว" ยังทำได้ตามปกติ — ปุ่มชวนเป็นทางเลือกรอง ขนาดเล็กกว่า
- **ไม่แสดงซ้ำ** ถ้าผู้ใช้กดปิด (✕) ในรอบนั้น
- ขนาดกระถางแนะนำ = `min(ขนาดเดิม + 2, 16)` นิ้ว (กติกาเดียวในโค้ด `lib/care/supplies.ts` เทสต์ได้)

## 3. Inquiry

- intent ใหม่ **`supplies`** (เพิ่มใน union `InquiryIntent` + zod + i18n + template)
- template LINE: `สนใจ{กระถาง 10 นิ้ว และดินปลูก|ปุ๋ย}สำหรับ "{ชื่อพันธุ์}" ครับ/ค่ะ (ตอนนี้กระถาง 8 นิ้ว เลี้ยงมา 11 เดือน) [TFL-XXXX]`
- `payload`: `{ userPlantId, kind: "repot"|"fertilizer", currentPotInch, suggestedPotInch, ageDays }`
- หลังบ้าน: inquiry `supplies` ติดป้ายสีต่างให้ร้านเห็นว่าเป็นลูกค้าเก่าซื้อซ้ำ
